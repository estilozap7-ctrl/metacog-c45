Sección 02

🧬 MetaCog-C45: Arquitectura Dual (Sistema 1 + Sistema 2)

MetaCog-C45 extiende el algoritmo clásico C4.5 (Quinlan, 1993) incorporando un Motor Metacognitivo de Sistema 2 inspirado en las teorías de doble proceso de la ciencia cognitiva.

⚡

Sistema 1 — C4.5 Inductivo Base

Generación rápida y heurística de candidatos de división mediante criterio de Gain Ratio y entropía de Shannon.

GR(S, A) = IG(S, A) / SI(S, A)
Función: Selecciona el umbral numérico que maximiza la ganancia de información normalizada, reduciendo el sesgo hacia atributos continuos.
🧠

Sistema 2 — Decision Core Metacognitivo

Evaluación deliberativa del candidato mediante perturbed bootstrap sampling y cálculo de utilidad Cobb-Douglas:

SCS = GR · NS^(α) · TS^(β) · (1 − CI)^(γ)
Componentes claves: Node Stability (NS), Threshold Survival (TS), Competitiveness Index (CI), MetaMemory e indexación de DecisionTrace.
