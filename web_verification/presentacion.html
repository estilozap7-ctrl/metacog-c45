Diapositiva 02

¿Qué es el Proyecto PyC45?

PyC45 es una implementación limpia, modular y orientada a objetos en Python puro del algoritmo clásico C4.5 (creado por Ross Quinlan en 1993) para tareas de clasificación binaria supervisada.

Objetivo del Framework:
Ofrecer una alternativa transparente e interpretable (caja blanca) frente a los complejos estimadores de librerías monolíticas, ideal tanto para la enseñanza académica como para la auditoría de reglas de negocio en entornos productivos.

🧠 Propósito Educativo

Código en español estructurado sin optimizaciones oscuras (Cython) para facilitar el debug paso a paso.

⚡ Enfoque Práctico

Preparado para datasets de la vida real con soporte integrado para variables continuas y poda REP.

Arquitectura y Estructura Modular

El framework está desarrollado siguiendo principios de **responsabilidad única** y cohesión interna, dividiendo sus componentes principales en carpetas independientes y auto-contenidas:

Contiene módulos de evaluación nativos (sin scikit-learn) para graficar curvas ROC y matrices de confusión detalladas.

Paso 1–3: Preparación

Lectura desde Pandas, eliminación de IDs, y división de datos. Un conjunto de validación (30%) es aislado para el proceso de poda.

Paso 4–5: Modelado

El árbol crece recursivamente seleccionando cortes óptimos. Después, la poda REP recorre el árbol de abajo a arriba colapsando ramas innecesarias.

Paso 6–7: Interpretación

Cálculo de ROC-AUC y ranking de variables. Generación del gráfico visual con Matplotlib y exportación interactiva web.

Diapositiva 05

El Núcleo Matemático: Criterio C4.5

1. Entropía de Shannon (Pureza)

Mide el grado de impureza de las clases en un nodo:

H(S) = - \sum p_i \log_2(p_i)

2. Ganancia de Información (Reduction)

Reducción neta de entropía al dividir por el atributo A:

IG(S, A) = H(S) - \sum \frac{|S_v|}{|S|} H(S_v)

3. Normalización con Gain Ratio (C4.5)

Evita el sesgo de IG hacia atributos con muchos valores dividiendo entre el Split Information:

GR(S, A) = \frac{IG(S, A)}{SplitInfo(S, A)}

Donde SplitInfo mide la entropía de la propia partición.

Manejo Numérico: C4.5 evalúa dinámicamente todos los puntos de corte medios consecutivos para variables continuas, seleccionando el umbral que maximiza el Gain Ratio.
Diapositiva 06

Simplificación y Control: Poda REP

La Poda por Error Reducido (**Reduced Error Pruning - REP**) es una técnica clave para evitar el sobreajuste y reducir la complejidad estructural del árbol de decisión.

¿Cómo funciona? OPERACIÓN BOTTOM-UP
Para cada nodo interno con hijos hoja, se evalúa si convertirlo en una sola hoja (prediciendo la clase mayoritaria local) mantiene o mejora la exactitud (accuracy) en el conjunto de validación independiente.

Si no hay pérdida de exactitud, el subárbol se elimina (colapsa). El proceso se repite recursivamente hacia arriba.

Antes de Poda (Sobreajuste)

El árbol crece libremente y memoriza detalles de los datos de entrenamiento (incluyendo ruido). Gran tamaño y profundidad, pero menor exactitud en validación.

Después de Poda (Generalización)

Las ramas que no aportan poder predictivo general sobre el conjunto de validación son colapsadas. Árbol compacto, rápido y fácil de interpretar.

Diapositiva 07

PyC45 vs. Algoritmo C4.5 Clásico

Lenguaje y Diseño
C4.5 Clásico: Código estructurado en C monolítico, difícil de integrar con flujos modernos de datos.
PyC45: Diseñado en Python 3 orientado a objetos. Legible, modular y documentado en español.
Entorno de Datos
C4.5 Clásico: Archivos planos propietarios (.names, .data).
PyC45: Carga nativa de dataframes de Pandas y matrices de NumPy. Total compatibilidad en pipelines de ciencia de datos.
Estrategia de Poda
C4.5 Clásico: Poda Pesimista basada en intervalos de confianza estadísticos estimados sobre train.
PyC45: Poda por Error Reducido (REP) utilizando un conjunto de validación externo e independiente.
Métricas y Visualización
C4.5 Clásico: Reportes básicos en consola con tasas de error generales.
PyC45: Curva ROC-AUC, coeficientes MCC/F1, importancia de variables y visualización interactiva.
Diapositiva 08

Aporte a la Analítica de Datos

🔍

Explicabilidad (XAI)

A diferencia de los modelos de "caja negra" (como Gradient Boosting o Redes Neuronales), PyC45 genera reglas de decisión explícitas y auditables, esenciales en finanzas, seguros y medicina legal.

🎓

Pedagogía Activa

Al ser código transparente en Python, permite a analistas y estudiantes desarmar y depurar el algoritmo paso a paso, comprendiendo a fondo el cálculo de la entropía, selección de umbrales y la poda recursiva.

📈

Métricas Robustas

Incorpora el Coeficiente de Correlación de Matthews (MCC) y curva ROC-AUC para evitar sesgos ante clases desbalanceadas (como en el caso del impago de tarjetas de crédito).

Explicabilidad Interactiva: La plataforma web de PyC45 cuenta con un trazador interactivo de caminos de decisión (Decision Path) para explicar individualmente la predicción de cualquier muestra.
Diapositiva 09

Conclusiones del Proyecto

El framework PyC45 consolida la aplicación de un algoritmo clásico a los estándares de desarrollo de software modernos.

  • Control absoluto: Permite modificar la lógica de partición y poda sin depender de librerías externas complejas.
  • Capacidad predictiva visible: El árbol identifica variables clave como PAY_0 (historial de morosidad reciente) de manera inmediata.
  • Punto de partida sólido: Establece una línea base (baseline) explicable antes de pasar a modelos más complejos.
